Prompt Vault — Design System

A living reference for the Prompt Vault frontend. Tokens and component styles here mirror frontend/src/index.css. The frosted surfaces and aurora backdrop are the app-wide glassmorphism look. Use the toggle above to preview light and dark.

Color tokens

A corporate dark base with a single amber-gold accent. Values shown are the dark theme; the light theme remaps the same variable names.

Typography

Display face is Space Grotesk (headings), body is Inter, and monospace is JetBrains Mono (code, values, run output).
